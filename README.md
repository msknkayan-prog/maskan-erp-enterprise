# Maskan ERP — Enterprise Final v1.0

نظام مؤسسي سحابي لإدارة أعمال **شركة مسكن الكيان للمقاولات**.

## الوحدات
- المشاريع والعملاء والمقاولون والموردون
- العقود والأعمال الإضافية والمطالبات
- طلبات الصرف والمستخلصات والدفعات والخصومات
- المشتريات والمخزون والعهد والسلف
- المستخدمون والصلاحيات وسجل الاعتمادات
- التقارير التنفيذية والنسخ الاحتياطي
- استيراد Excel وCSV مع المعاينة والتحقق

## التقنية
- واجهة ويب متعددة الملفات تعمل مباشرة على Vercel
- Supabase للمصادقة وقاعدة البيانات والتخزين
- PWA للجوال
- GitHub Actions لفحص الجودة قبل النشر

## النشر
1. ارفع **محتويات المشروع** إلى مستودع GitHub.
2. اربط المستودع بمشروع Vercel واحد.
3. اختر الفرع `main` للإنتاج.
4. لا تضع أي مفتاح `service_role` أو مفتاح سري داخل المستودع.
5. افتح النظام وشغّل فحص الجاهزية من إعدادات النظام.

## ترتيب إدخال البيانات
الجهات ← المشاريع ← العقود ← طلبات الصرف ← المستخلصات ← الدفعات.

## الفروع المقترحة
- `main`: النسخة الإنتاجية المعتمدة.
- `development`: التطوير والتجارب.

راجع `docs/DEPLOYMENT_AR.md` و`docs/ACCEPTANCE_AR.md`.
