# مسكن الكيان ERP — النسخة الإنتاجية النهائية

نظام سحابي لإدارة المشاريع والعقود والمستخلصات والدفعات والمشتريات والمخزون.

## التشغيل
1. ارفع ملف ZIP إلى Vercel كمشروع جديد.
2. افتح الرابط عبر Visit.
3. سجّل الدخول بحساب المدير الحالي.
4. من **إعدادات النظام** شغّل **فحص جاهزية قاعدة البيانات**.
5. ابدأ بإضافة الجهات، ثم المشاريع، ثم العقود.

## مزايا النسخة النهائية
- ربط مباشر مع Supabase.
- صلاحيات المستخدمين وRLS.
- بحث شامل وإضافة سريعة.
- دورة اعتماد مالية وتشغيلية.
- تقارير وتصدير وطباعة.
- نسخة احتياطية JSON.
- فحص تشخيصي لجاهزية قاعدة البيانات.
- إغلاق تلقائي للجلسة بعد ساعة من عدم النشاط.
- دعم الجوال والوضع الداكن وPWA.

## الأمان
لا يحتوي المشروع على Service Role Key أو Secret Key.
